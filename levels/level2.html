The Inspector's Eye

Just because something is invisible doesn't mean it isn't there.

The second scroll was torn in two. The first half was hidden on this page by a ninja who knew how to make things vanish. The second half was hidden in the page's style.

Put both halves together to make the full flag.

First half of scroll #2: RyzenRonin{1nsp3ct_3

Nice try, but this is a decoy: RyzenRonin{n0t_th1s_0n3}

Hint 1

Open Developer Tools (F12) and look at the Elements (Chrome/Edge) or Inspector (Firefox) tab. CSS can hide elements that are still in the HTML.

Hint 2

This page loads more than one stylesheet. Check the <head>, then open the Sources / Style Editor tab, or just open the stylesheet URL directly.

Hint 3

Developers leave comments in CSS too: /* like this */. Watch out for decoys, since only one first half matches the story.
