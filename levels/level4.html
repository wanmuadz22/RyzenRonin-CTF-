The Client-Side Gatekeeper

A lock is useless if you hand the key to everyone who walks up to the door.

Only the sensei may log in to read scroll #4. The dojo couldn't afford a real server, so the gatekeeper checks the password right here in your browser.

Think about it: if your browser checks the password, then your browser must know the password…

Sensei Login

Hint 1

View the page source. Where does the login logic come from? Look for a <script src=...> tag and open that file.

Hint 2

The password isn't encrypted, only encoded. That string of letters and numbers is Base64. The code even uses btoa(), which is JavaScript's Base64 encoder.

Hint 3

Open the DevTools Console and run atob("the_encoded_string") to decode it. Or use CyberChef's "From Base64" recipe.
